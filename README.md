# 📊 Retail Sales Dashboard | Excel Business Intelligence Project

An interactive **Business Intelligence Dashboard** built using **Microsoft Excel, Power Pivot, and DAX** to analyze retail sales performance and transform raw transactional data into meaningful business insights.

The dashboard enables decision-makers to monitor business performance, evaluate sales trends, identify revenue drivers, and compare current performance with the same period in the previous year using advanced **Time Intelligence** calculations.

# 📌 Project Objectives

This dashboard was developed to answer the following business questions:

- How is the business performing overall?
- What are the most important business KPIs?
- Which categories generate the highest revenue?
- Which brands contribute the most to sales?
- Which states, customers, stores, and products drive business performance?
- How does current performance compare with the same period last year?
